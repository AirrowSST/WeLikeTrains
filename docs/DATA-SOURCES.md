No Telegram/web-page scraping is used. No private commuter data was acquired. Public landmarks in the catalog are demo endpoints, not real residents’ addresses. Online map display requests only the visible OneMap tiles; this necessarily exposes the client IP address and requested tile coordinates to SLA’s service. Named-stop search and route computation use only committed OSM-derived files, and the app falls back to its bundled vector map when OneMap is unavailable. No public geocoding or routing server, advertising, or analytics layer is loaded. Web fonts are bundled locally. Lucide icons, Leaflet, React and other packages retain their published licences in npm dependencies; consult the lockfile for exact versions.

## OSM provenance and refresh

`data/OSM-PROVENANCE.json` records extraction time, source, bounding box and query; `scripts/import-osm.mjs` contains the exact bounded split queries and station-code join. The snapshot is WGS84: network coordinate tuples are latitude/longitude, GeoJSON is longitude/latitude. The organiser’s missing station polygon file was not used, and its CRS was not guessed.

`npm run data:osm` is a **manual maintenance command**, not part of app startup, build or CI. It reuses `.cache` and spaces new bounded downloads. For a fresh extract, archive the specific cache files deliberately or use a new checkout; do not repeatedly query a public Overpass server. Respect its load policy or use a managed/self-hosted endpoint (`OVERPASS_URL`) for large refreshes. The running application never contacts Overpass, public geocoding, or public routing providers. It contacts OneMap only for visual tiles when online. Cloud Run serves the committed OSM vectors and the backend loads the committed routing graph directly.

The derived extract includes all fetched supported rail route relations and selected buses (2, 12, 17, 27, 34, 36, 67, 118, 190, 196); unmapped, future or incomplete services are not a promise of operational service. Rail names/codes can change. Retain attribution and the ODbL obligations when redistributing modified database files. App code licensing is left to the repository owner; no third-party data ownership is claimed.
